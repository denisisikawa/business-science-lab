# Portfolio avatar

Approved 16-bit portrait of Denis Isikawa, generated from his LinkedIn photo and recolored to match this site's burgundy, gold and cream palette.

- `denis-avatar-96.png`: header mark, displayed at 48 CSS pixels (40 on narrow screens).
- `denis-avatar-480.png`: introduction portrait, displayed at 176 CSS pixels (144 on narrow screens).
- `../../favicon-32.png`: tighter face crop reduced to 32 pixels for browser tabs.
- `../../favicon.svg`: SVG wrapper containing the same 32-pixel crop, with no external dependency.
- `../../apple-touch-icon.png`: 180-pixel icon for saved home-screen shortcuts.

All PNGs are below 1 MB. Derivatives use nearest-neighbor resampling to preserve pixel edges. The header image has empty alternative text because the adjacent name labels the home link; the larger portrait has descriptive alternative text. Fixed width and height reserve image space during loading.
